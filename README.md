## 🌟 Overview

This repository houses the personal portfolio and software engineering showcase of **Abhinav Tiwary** (AI/ML Engineer & Full-Stack Developer).

It merges scroll-driven video scrubbing, fluid GSAP micro-animations, 3D WebGL effects, native privacy analytics, and an administrative CMS dashboard to highlight 12 verified open-source engineering systems across Full-Stack, Autonomous Agents / LLMs, and Machine Learning.

---

## 🚀 Key Featured Projects

1. **[DecisionForge](https://github.com/abhinavtiwary15/Decisionforge)**: Enterprise GST Input Tax Credit audit intelligence platform combining Google BigQuery analytical views with Gemini explanations protected by a numeric-grounding verification guard.
2. **[AgentGuard](https://github.com/abhinavtiwary15/AgentGuard)**: Autonomous AI Security Operations Center orchestrating 5 specialized Azure OpenAI agents for real-time threat triage, investigation, and automated containment.
3. **[Credit Card Fraud Detection](https://github.com/abhinavtiwary15/Credit-Card-Fraud-Detection-ML)**: Calibrated, leakage-free fraud classification pipeline on 284K+ transactions with SMOTE in-pipeline oversampling, tuning operating thresholds to boost precision to 87.5% at 78.6% recall.

Explore all 12 projects on the `/projects` showcase route.

## 🛠️ Tech Stack

- **Frontend & Core Engine**: Next.js 15 App Router, React 19, Tailwind CSS v4, Lenis Smooth Scroll
- **Motion & 3D Graphics**: GSAP 3, ScrollTrigger, Three.js, React Three Fiber, Framer Motion
- **Database & Storage**: Supabase (PostgreSQL, Row Level Security, Object Storage Buckets)
- **Email Service**: Resend API
- **Authentication**: JWT (`jose`) session tokens for admin portal
- **Analytics & Observability**: Native database session tracking, page view logging, and search query analytics

## ⚙️ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/abhinavtiwary15/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Configure environment variables
# Copy .env.local.example to .env.local and populate credentials
cp .env.local.example .env.local

# 4. Start local development server
npm run dev
```

Visit [`http://localhost:3000`](http://localhost:3000) to view the application.
